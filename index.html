🛍️ 前台上架狀態

如果你正在整理商品、上傳新款，可以暫時關閉選花店前台。
關閉後客人會直接看到「目前正在上架新款式，等等再過來看看嗎？」。

🧺 圖片揀貨模式

把客人傳給你的「訂購文字」整段貼到下面，按「開始圖片揀貨」。

系統會自動把 🌸 花朵、🎀 蝴蝶結、🫙 玻璃瓶變成圖片卡片。
你只要照著圖片一個一個點，撿完就打勾。
🎉 全部都撿好了！可以交給客人囉 ♡

🌸 花朵商品管理

商品多了不用一直滑：可以搜尋、全部收合／展開，還可以只看「低庫存」或「已售罄」。
點開商品後直接修改名稱、圖片、價格、庫存；全部改好後只按一次「儲存全部商品」即可。上方也有固定的儲存按鈕，不用滑到底。
新增新商品仍然使用上面的表單。
📦 批次新增／更新商品
貼上商品資料後，按你要新增的類別。
圖片可以只填檔名，例如 A01.jpg、r1.jpg、b1.jpg，系統會自動補成 GitHub 圖片網址。

🎀 蝴蝶結管理

每個蝴蝶結都可以修改。現在不用每個按一次，全部改好後按一次下面的「儲存全部蝴蝶結」。

💰 款式價格

所有價格可以一起改，最後只按一次「儲存全部價格」。

🫙 玻璃瓶管理

所有玻璃瓶可以一起修改，最後只按一次「儲存全部玻璃瓶」。

🎀 作品管理

這裡可以管理「作品」頁面。每一張作品都可以填圖片網址與作品名稱，也可以一直新增、修改或刪除。
圖片請貼上可以直接開啟圖片的網址，例如 GitHub Raw 圖片網址。

🔗 網站連結

每一列都是一個連結：左邊填你想顯示的「連結名稱」，右邊填完整「網址」。可以一直新增、刪除或修改；全部完成後只按一次「儲存全部連結」，會同步到 Cloudflare。

💾 後台總儲存

平常可以分區儲存；如果你一次改了很多地方，全部改完後也可以用這顆。網站連結會同步到 Cloudflare KV。
